# LILO PULSE 🪐

**Tu compañero para operar el estirón de las noticias grandes** (NFP, CPI, FOMC).

Una página simple, en el celular o la compu: calendario con cuenta regresiva,
qué par se mueve, el medidor de **"empujón fuerte"**, checklist antes de la
noticia, y un paso a paso para no ponerte nervioso. En 3 idiomas (🇦🇷 ES / 🇬🇧 EN /
🇧🇷 PT) y con selector de zona horaria.

👉 **Probala acá:** (se activa cuando prendas GitHub Pages — abajo dice cómo)

---

## Qué hace

Cuando sale una noticia fuerte, el precio suele pegar un **estirón**. LILO te
ayuda a prepararte y a entrar con disciplina, de dos formas:

- **Forex (la más segura):** compra arriba y venta abajo (straddle). Salta una,
  buscás ganar 2–3 veces lo que arriesgás. Como es **2 a 1, sos rentable desde el
  33%** de acierto — y la base histórica ronda el ~60%. Margen cómodo, y cuando
  perdés no perdés todo.
- **Binarias con órdenes pendientes:** solo con el **empujón fuerte** (si el primer
  minuto se mueve ≥8 pips) la efectividad sube a ~**71%** (contra ~63% si entrás a
  todas). Sin ese filtro, el margen es muy justo.

## Lo honesto (para no venderte humo)

Esto **no es una máquina de plata.** Es un **ayudante de disciplina + calendario**,
no una señal mágica. El borde es finito y depende de que respetes el filtro del
empujón fuerte.

- Empezá **chico** y en **cuenta propia**.
- La versión **más segura es el forex 2 a 1**, no las binarias.
- El resultado **en vivo es el juez final.**

## Cómo usarla

Abrís la página, elegís tu idioma y tu zona horaria, y listo: te muestra la
próxima noticia grande con la cuenta regresiva. Dos minutos antes dejás tus
órdenes, y cuando sale mirás el medidor de empujón. Todo corre en tu navegador,
no guarda nada tuyo en ningún lado.

## Para publicar el link (GitHub Pages)

1. En este repo: **Settings → Pages**.
2. En *Build and deployment*, *Source*: **Deploy from a branch**, rama **main**,
   carpeta **/ (root)**. **Save**.
3. A los minutos, arriba aparece el link público (algo como
   `https://TU-USUARIO.github.io/lilo-pulse/`). Ese es el que compartís.
